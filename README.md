# Library Frontend

A simple React project with three pages:

- **Login** (`/`) - login and create account forms
- **Books** (`/books`) - list of books and their total price
- **Office** (`/office`) - save, search and delete offices (needs the backend running on port 8081)

## How to run

1. Install the packages: `npm install`
2. Start the project: `npm run dev`
3. Open the link shown in the terminal (usually http://localhost:5173)
